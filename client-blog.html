构建高可用统一身份认证体系：基于 accounts.yaoxi.cloud 与 WebAuthn 通行密钥的跨域实践

作者: yaoxi (管理员) · 发布于 2026-08-21 · 阅读时长 8 分钟

在 blog.yaoxi.wiki 体系中，将认证授权独立至 accounts.yaoxi.cloud 专属域名，实现了基于 FIDO2 / WebAuthn 通行密钥（Passkey）的无密安全单点登录。

登录流程严格限制管理员账号 yaoxi，第一步输入账号，第二步直接调起真机硬件通行密钥断言（Passkey Assertion），完成后以 RS256 JWT Token 实时跨域回传并完成签名校验...

🎉 管理员权限已激活：yaoxi (通过通行密钥硬件签名认证)

【跨域安全架构设计】：认证中心 accounts.yaoxi.cloud 签发的 JWT Token 中声明了 iss: https://accounts.yaoxi.cloud 与 sub: yaoxi，客户端 blog.yaoxi.wiki 接收到 Hash 路由或 postMessage 广播后，可离线快速校验签名真实性，杜绝中间人劫持与越权攻击。 

// 跨域向 accounts.yaoxi.cloud 发起认证跳转
const authUrl = new URL('https://accounts.yaoxi.cloud/oauth/authorize');
authUrl.searchParams.set('client_id', 'yaoxi-blog');
authUrl.searchParams.set('redirect_uri', 'https://blog.yaoxi.wiki');
authUrl.searchParams.set('response_type', 'token');
authUrl.searchParams.set('scope', 'openid profile email admin');
window.location.href = authUrl.toString();
