构建高可用统一身份认证体系：基于 accounts.yaoxi.cloud 与 WebAuthn 通行密钥的跨域实践

作者: 架构团队 · 发布于 2026-08-21 · 阅读时长 8 分钟

在 blog.yaoxi.wiki 架构中，客户端发起授权请求时携带随机生成的 client_request_token 并建立实时握手监听；认证中心 accounts.yaoxi.cloud 首屏嵌入 Cloudflare Turnstile 人机验证，完成后调用浏览器底层的 FIDO2 / WebAuthn 硬件通行密钥断言，并将数字签名实时回传至博客端。

认证中心界面保持严格的中立隐私规范，支持通行密钥与密码双重认证方式，保障系统凭证的安全隔离与高可用...

🎉 权限已激活：通过 accounts.yaoxi.cloud 硬件签名跨域实时认证

【跨域实时签名验证架构】：blog.yaoxi.wiki 监听并校验由 accounts.yaoxi.cloud 签发的 RS256 签名，比对发起请求时的 client_request_token 防范重放攻击。 

// blog.yaoxi.wiki 携带 Token 发起请求
const requestToken = 'crt_' + crypto.randomUUID();
const ssoUrl = new URL('https://accounts.yaoxi.cloud');
ssoUrl.searchParams.set('client_request_token', requestToken);
ssoUrl.searchParams.set('client_id', 'yaoxi-blog');
ssoUrl.searchParams.set('target_domain', 'blog.yaoxi.wiki');

// 实时监听 accounts.yaoxi.cloud 回传签名
window.addEventListener('message', (event) => {
  if (event.data?.type === 'YAOXI_SSO_SIGNATURE_CALLBACK') {
    assertSignature(event.data.signed_token, requestToken);
  }
});
